# 知六：14天六级冲刺

平板优先的静态离线学习程序。程序与个人真题资料分离：此公开目录不含试卷图、录音或PDF。用户通过资料包JSON导入至IndexedDB，在自己的设备离线使用。

## 使用
1. 首次联网打开网站，等待“程序离线就绪”。
2. 在“历年真题库”导入交付的个人资料包JSON；显示资料完整后，再添加到主屏幕。
3. 断网验证可打开题图和播放录音。不要清除浏览器数据；定期导出学习记录备份。

## 功能与边界
14天固定任务、词汇SM-2间隔复习、真题图片阅读、听力倍速播放、答题卡、已核验答案自动批改、错题回流、写译草稿、自查与复盘、首次/最近成绩报告、离线缓存、JSON进度导入导出。
每天约90分钟，最后一天85分钟；听读300题次覆盖260道不同真题，另有140题次词汇测试；学习门槛不等同正式考试评分。没有“14天必过”承诺、云同步、AI作文评分或笔迹识别。
资料不齐全的试卷明确标示，不生成猜测答案。版权与来源保留在各套metadata；下载可用于个人学习，不代表已获公开再分发许可。

## 开发
无构建依赖。用任意静态HTTP服务器提供本目录。Service Worker需HTTPS或localhost；应用数据仅保存在浏览器localStorage/IndexedDB。更新发布时刷新sw.js内容版本以触发缓存更新。
