# 知六 · 六级学习工作台

打开 https://lizexuan581-stack.github.io/cet6/ 即可选卷作答。首页提供自由练习、历年真题、最近学习记录和独立的 14 天冲刺入口。

原卷来自目录中标注的公开来源。浏览器按需读取题图、PDF、解析和录音。题卷界面可逐卷保存以供离线练习。已有的个人资料包也可在“资料与离线”中恢复。学习记录保存于当前浏览器。

14 天计划使用 6 份试卷，听读练习共 300 题次，其中 260 道不同真题。已核验答案的客观题自动批改，写译支持草稿、修改记录和自查。

通过 HTTPS 或 localhost 提供本目录即可运行。安装离线程序后，在准备长期使用的浏览器或主屏幕应用中保存需要的试卷。内置 PDF 阅读使用 Mozilla PDF.js，授权文件随代码提供。
